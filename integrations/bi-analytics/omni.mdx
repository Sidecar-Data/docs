## 1. Create an API Key

1. Log in to your **Omni** console.
2. Navigate to **User Settings** > **API Keys**.
3. Click **Generate New Token** and copy the token to a secure location.

This token will be used as your **API Key** when setting up the integration.

## 2. Connect Omni to Sidecar

In the Sidecar integration setup screen, enter the following credentials:

| Field | Description |
|-------|-------------|
| **Host** | The URL of your Omni workspace (e.g., `https://yourcompany.omniapp.co`) |
| **API Key** | The token you generated in Step 1 |

Click **Test Connection**. If the connection is successful, click **Save**.
