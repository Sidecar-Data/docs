## Prerequisites

- A Sigma member with the **Admin** account type
- The warehouse that Sigma reads from, connected to Sidecar (for example, [Snowflake](/integrations/data-warehouses/snowflake))

## 1. Create API client credentials

1. In Sigma, select your user avatar, then select **Administration**.
2. In the side panel, select **Developer access**.
3. Copy the **API base URL** at the top of the page.
4. Click **Create new**.
5. Under **Select scopes**, select **REST API**.
6. For **Name**, enter `Sidecar`.
7. For **Owner**, select a member with the **Admin** account type.
8. Click **Create**.
9. Copy the **Client ID** and **Client secret**, and save them in a password manager.

<Warning>
  Sigma shows the client secret only once. If the owner is deactivated, Sigma deactivates the credentials too, and you need to create new ones.
</Warning>

## 2. (Optional) Allow Sidecar's IP address

If your organization restricts Sigma access with an IP allowlist, add Sidecar's IP address:

1. In Sigma, select your user avatar, then select **Administration**.
2. In the side panel, select **Authentication**.
3. In the **IP address** section of the **IP allowlist**, select **Add**.
4. For **Scope**, select **API**.
5. For **IP address or CIDR range**, enter `44.236.246.98/32`.
6. Click **Save**.

## 3. Connect Sigma to Sidecar

Provide the following information to the Sidecar team:

| Field | Description |
|-------|-------------|
| **API base URL** | From step 1, for example `https://aws-api.sigmacomputing.com` |
| **Client ID** | From step 1 |
| **Client secret** | From step 1 |
